# ROADMAP.md

> Factory의 개발 단계  
> Development phases of the Factory

## Foundation

### Goal

- Factory의 존재 목적, 역할, 구조, 최소 설정을 확정한다
- Establish the Factory purpose, roles, structure, and minimal configuration

### Exit Criteria

- 핵심 Foundation 문서가 존재한다
- Core Foundation documents exist
- Factory 최소 설정이 존재한다
- Minimal Factory configuration exists
- 저장소 진입 경로가 명확하다
- The repository entry path is clear

## Core

### Goal

- Factory가 제품을 다룰 수 있는 핵심 기준을 갖춘다
- Equip the Factory with core criteria for handling products

### Exit Criteria

- 제품, 디자인, 검증의 권한 문서가 정의된다
- Authoritative documents for product, design, and verification are defined
- Decision 기록이 가능한 위치가 확정된다
- The place for Decision records is established

## Templates

### Goal

- 반복 가능한 산출물 템플릿을 갖춘다
- Provide reusable templates for repeatable artifacts

### Exit Criteria

- 문서와 구조에 재사용 가능한 템플릿이 존재한다
- Reusable templates for documents and structure exist
- 템플릿이 특정 제품에 종속되지 않는다
- Templates are not tied to a specific product

## Toolchains

### Goal

- Factory 작업을 지원하는 도구 경계를 정의한다
- Define the tool boundaries that support Factory work

### Exit Criteria

- 필요한 도구 범주가 정의된다
- Required tool categories are defined
- 도구 선택이 제품 구현 세부사항과 분리된다
- Tool choices remain separated from product implementation details

## Automation

### Goal

- 반복 작업을 자동화할 수 있는 기반을 마련한다
- Establish a foundation for automating repeated work

### Exit Criteria

- 자동화 대상과 비대상이 구분된다
- Automation targets and non-targets are distinguished
- 자동화가 최종 결정을 대체하지 않는다
- Automation does not replace final decisions

## Release

### Goal

- Factory를 재사용 가능한 상태로 공개할 수 있게 한다
- Make the Factory ready for reusable release

### Exit Criteria

- Foundation부터 Automation까지의 기준이 충족된다
- Criteria from Foundation through Automation are met
- 라이선스와 진입 문서가 공개 상태를 지원한다
- License and entry documents support a public state
