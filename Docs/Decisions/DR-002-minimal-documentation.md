# DR-002 — Minimal Documentation

상태 / Status: Accepted

## 결정 / Decision

핵심 문서는 README, AGENTS, PRODUCT, ARCHITECTURE, DESIGN, ROADMAP, SETUP과 소수의 Decision만 유지한다.

한국어를 기준 언어로 사용하고 영어를 함께 제공한다. 별도의 한국어/영어 파일을 만들지 않는다.

## 이유 / Rationale

문서가 많아질수록 권한 충돌, 중복, 오래된 정보, AI의 잘못된 참조가 증가한다. 하나의 문서가 하나의 주제에 대한 권한을 가져야 한다.

## 결과 / Consequences

- 같은 내용을 여러 문서에 복사하지 않는다.
- 작업 기록을 장문의 스프린트 일지로 계속 누적하지 않는다.
- 필요할 때 현재 상태를 권한 문서에 반영한다.
- 되돌리기 어려운 결정만 Decision으로 남긴다.

---

## English Summary

The project keeps only a small set of authoritative documents. Korean is primary and English is provided alongside it in the same files. Duplication and long-running sprint-history documents are avoided.
