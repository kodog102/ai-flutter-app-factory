# DR-002 — 최소 문서화

상태: 승인됨

## 결정

핵심 문서는 README, AGENTS, PRODUCT, ARCHITECTURE, DESIGN, ROADMAP, SETUP과 소수의 Decision만 유지한다.

사람이 읽는 설명 문서는 한글로 작성하며 같은 내용을 영어로 반복하지 않는다. 코드 식별자, 공개 API 이름, 파일 경로, 명령, 구성 키와 실행 리터럴은 원문을 유지할 수 있다.

## 이유

문서가 많아질수록 권한 충돌, 중복, 오래된 정보, AI의 잘못된 참조가 증가한다. 하나의 문서가 하나의 주제에 대한 권한을 가져야 한다.

## 결과

- 같은 내용을 여러 문서에 복사하지 않는다.
- 작업 기록을 장문의 스프린트 일지로 계속 누적하지 않는다.
- 필요할 때 현재 상태를 권한 문서에 반영한다.
- 되돌리기 어려운 결정만 Decision으로 남긴다.
