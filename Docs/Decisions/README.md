# Decisions

> Decision Record 관리  
> Decision Record management

## Purpose

- 되돌리기 어려운 결정을 기록한다
- Record hard-to-reverse decisions
- 결정의 상태와 이력을 추적한다
- Track the status and history of decisions

## Naming Convention

- 파일 형식: `DR-001-short-title.md`
- File format: `DR-001-short-title.md`
- 번호는 증가만 한다
- Numbers only increase
- 번호는 재사용하지 않는다
- Numbers are not reused

## Status

- `Proposed`
- `Accepted`
- `Superseded`
- `Deprecated`

## Lifecycle

- 기본 흐름: `Proposed` → `Accepted` → `Superseded` (optional)
- Default flow: `Proposed` → `Accepted` → `Superseded` (optional)
- `Deprecated`는 예외적인 경우에만 사용한다
- Use `Deprecated` only in exceptional cases
